# Country-event statistics

This statistic ranks the countries that host official results. It does not use a
competitor's nationality.

The country pages are `/countries/fastest-single`,
`/countries/fastest-average`, `/countries/competitors`,
`/countries/competitions`, and `/countries/solves`. The API has matching paths
under `/api/countries/`.

All pages accept event, continent, year, and gender filters. The ranking type
or count statistic is part of the path, not a query parameter.
